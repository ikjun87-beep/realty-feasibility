# 강화 내리 3필지 전원주택부지 개발 검토

인천 강화군 화도면 내리 **144-1 · 140-1 · 140-3**을 3획지 전원주택부지로 분할·매각하고,
가설계/3D를 검토하는 사업성 검토 프로젝트.

## 대상 필지 (VWorld 연속지적도 실측, 2025 공시지가)

| 필지 | 지목 | 면적 | 공시지가/㎡ | 도로 접함 | 비고 |
|------|------|------|-------------|-----------|------|
| **144-1** | 대지 | 700.7㎡ (212평) | 133,100 | 42m ✅ | 가장 우량, 진입로 관통 필지 |
| 140-1 | 묘지 | 181.9㎡ (55평) | 46,700 | 0m ⚠️ | 맹지 |
| 140-3 | 묘지 | 953.8㎡ (288.5평) | 70,700 | 2.7m ⚠️ | 진입 불량 |

- 합계 ≈ **555.5평 (1,836㎡)**, 공시총액 ≈ 1.69억
- 용도지역: 3필지 모두 **계획관리지역** (건폐율 40%·용적 100%, 단독주택 건축 가능)
- 실거래 반영 예상 매각가: **합산 4.4~5.9억** (화도면 실거래 평당 84만 중앙값 기준)

## 핵심 제약 (매각 성립 조건)

1. 140-1·140-3이 지목상 **묘지** → 지목변경 필요 (단, **실제 분묘 없음 — 현장 확인 완료** → 이장/분묘기지권 이슈 없음, 지목변경만으로 대지 전환 = 최상 시나리오)
2. 뒤 두 필지 진입 불량 → **144-1 도로변(42m) 관통 공유 진입로 필수**
3. 화도면(마니산·갯벌·접경) 군사·문화재·습지 규제 중첩 가능 → **토지이용계획확인원 우선 확인**

## 산출물

| 파일 | 내용 |
|------|------|
| `index.html` | 지적검토 종합 리포트 (필지·가격·팩트체크·가설계) |
| `house.html` | 전원주택 가설계 + canvas 3D (25평형 3룸 모던 단층+다락) |

| `map_data.json`, `parcels.geojson` | 연속지적도 데이터 |
